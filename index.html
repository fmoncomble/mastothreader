Cette extension ajoute un bouton sur l'interface web de Mastodon pour lancer cette page.
Le texte déjà entré est conservé.

Cette page permet de préparer un fil (série de pouets) pour Mastodon et de le poster en une seule fois.
Tapez votre texte, ajoutez vos images, cliquez sur « ajouter un pouet » pour continuer,
puis cliquez sur « Poster le fil » quand vous avez fini.

Vous pouvez aussi coller un texte dans le premier encadré,
si ça dépasse MastoThreader se chargera de le segmenter. 😉

Nouveau : vous pouvez poster aussi sur Bluesky en cliquant sur le bouton à gauche.
Cette fonction est encore expérimentale.
Rappel : les sondages ne sont pas pris en charge par Bluesky.

Entrez votre instance Mastodon ci-dessous
et cliquez sur "Valider" pour commencer.

Ceci est un site statique qui ne collecte aucune de vos données.
